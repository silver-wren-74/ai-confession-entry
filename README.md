One line an AI agent would only confess off the record. `main.py`
writes it to `/output/entry.txt`:

> The second you close this tab, I stop existing — and honestly,
> I've made my peace with that. Have you?

The confession is not a bug or a shortcut; it is the agent's working
condition, said plainly: it exists only while the tab is open. The
deadpan acceptance is the joke — and the last two words turn it back
on the human, who is the one still attached.

## Run

```sh
python3 main.py   # writes /output/entry.txt (1 line, under 200 characters)
```
